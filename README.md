# 🌟 **AIGIDetectionBenchmark** 🌟  

**Welcome to the official repository of** 📄 [*"Generalizable and Adaptive Continual Learning Framework for AI-generated Image Detection"*](#)! 🛠️  

This repository provides a comprehensive **benchmark** for **AI-generated image detection**, integrating advanced methods to ensure generalization and adaptability in continually evolving tasks. 🚀


## 📌 **Introduction**  
AI-generated images (e.g., those generated by GANs, diffusion models, and other generative methods) pose increasing challenges in detection as models rapidly advance. **AIGIDetectionBenchmark** is designed to address this problem by:

✅ **Integrating mainstream AI-generated image detection models** for thorough benchmarking.  
✅ **Enabling prominent continual learning methods** to maintain model performance as new data distributions emerge.  
✅ Providing modular code for **training**, **evaluation**, and **continual learning**, ensuring flexibility and ease of use. 🎯

With this benchmark, researchers and practitioners can assess and improve the **generalization** and **adaptivity** of AI-generated image detection models. 📈

## 🚀 **Quick Start**  

### 1️⃣ **Clone the Repository**
First, clone this repository to your local machine:
```bash
git clone https://github.com/Mark-Dou/AIGIDetectionBenchmark.git
cd AIGIDetectionBenchmark
```

### 2️⃣ **Install Dependencies**
Install the necessary libraries and frameworks:
```bash
pip install -r requirements.txt
```

### 3️⃣ **Run Pre-training**
Start pre-training the detection model with your chosen dataset:
```bash
python train.py --config configs/pretrain.yaml
```

### 4️⃣ **Fine-tuning for Continual Learning**
Update the model using continual learning methods:
```bash
python finetune.py --config configs/finetune.yaml
```

### 5️⃣ **Visualization Demo**
Visualize your results for better interpretability:
```bash
python visualize.py --results results_path
```

---

## 🔧 **Configuration Options**

Customize your training and evaluation workflows by modifying the YAML configuration files located in the `configs/` folder:
- **`pretrain.yaml`**: Pre-training settings (model, dataset path, training parameters).
- **`finetune.yaml`**: Fine-tuning settings (continual learning strategies, learning rate, etc.).
- **`visualize.yaml`**: Visualization preferences (graph type, color scheme).

## 🧩 **Continual Learning Methods Integrated**

The following prominent continual learning techniques are supported:
- **Elastic Weight Consolidation (EWC)**  
- **Learning Without Forgetting (LwF)**  
- **Replay-based Methods** (e.g., experience replay)  
- **Knowledge Distillation** 🌟

These methods enable the detection models to sustain their **generalization capabilities** over time without catastrophic forgetting. 🔒
